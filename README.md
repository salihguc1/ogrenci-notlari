# Not Defteri

Performans ve proje notlarını iPhone'dan hızlıca girip e-Okul düzeninde Excel'e ve imzaya hazır PDF'e aktaran web uygulaması.

Notlar ve öğrenci listeleri yalnızca telefonda saklanır; bu depoda öğrenci verisi yoktur.

Kurulum: adresi iPhone'da Safari ile açın → Paylaş → Ana Ekrana Ekle.
